> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 固定音色的长文分段、按现有静音补停顿、全篇恒定增益及真实采样点映射。
**Architecture:** 独立 planning/speech、media/narration 和 adapters/longform 模块，复用 03/04/05 契约；较细独立 TTS 提供真实边界。
**Tech Stack:** Python 3.12 标准库、pytest、本地 VoxCPM2 CUDA 服务。
**Spec:** [TTS-VOX-06-design.md](../../task-designs/TTS-VOX-06-design.md)。

## Review Focus

- 纯空白、标点、长句、重复文字和中英混排必须保留全部原文；不能提交无语音请求。
- 情绪计划可很细，但音色/模型/种子必须全篇固定，单元不得超过 250 字。
- 边界已含静音时只补差额；尾音不得被剪掉。
- 中途失败不得留下成功旁白；对齐必须源自实际采样点。
- 无强制对齐器时保持细粒度生成，不跨句后伪造句级时间。

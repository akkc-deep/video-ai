# 保留低刺激发声，只换男声音色

**后续反馈：两版仍太低沉，刻意哄睡感生硬。** 已改为[清亮自然聊天式男声](voxcpm2-bright-casual-voice.md)的新试听方向；下述 A/B 均未获用户接受，不应作为 07 的默认音色。

用户反馈 v3 “感觉快对了，这个音色不好”。因此保留低刺激、轻声、平稳、无底音的方向，仅提供两个不同的男声参考供试听，不重新升调或叠加频率效果。

两版使用与 v3 相同的参考原文及正文、正文 seed=42 / cfg=2 / steps=20、0.75 倍语速、1.2 秒段间停顿、轻减高频和全篇 RMS 目标 -25dBFS。A/B 各自两段共用其固定参考，不在段间换音色。TTS 换参考后实际节奏仍可能有差异；“相同设置”不等于波形或主观听感完全相同。

- **A：清润男声方向。** 参考设计倾向清澈温润的青年男声、柔软干净、轻声放松。
- **B：温和圆润男声方向。** 参考设计倾向温和清爽的成年男声、自然交谈感、柔和圆润。

参考设计种子分别为 142 和 242，以产生新的音色候选；每版的正文生成种子均固定为 42。标签描述设计方向，不代替主观试听。两个参考均为模型生成的通用男声，不克隆具体人物。

本轮只作有限音色试听，不重复完整长文、视频、ASR 或无关回归。新资产/音频均独立保存，选中的持久音色暂不更换，仅记录 `voice_replacement_pending` 与两个候选路径。现有低刺激方向继续保留，最终音色待用户选择后才能冻结供 07 使用。

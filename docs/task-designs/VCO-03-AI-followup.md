# VCO-03 AI校准补充实验 v2

用户要求继续处理AI校准，不填写人工表。上一版240项结果、标签、阈值及检查侧保持封存。本轮只使用原校准侧开发，用未进入原24源的CC0 `shotstack_scott` 96个已就绪原生帧做新的小规模检查；媒体血缘与原24源无已知哈希重叠，不声称已证明拍摄独立或跨题材泛化。

校准侧诊断显示：累计色漂仅三段case有分数，52条normal都落在两段case，形成0个有效正常样本；动作突变原弱标签没有normal。动作正例10条中5条标在background，相机正例20条中10条标在subject，属于不适用的区域/检测项配对。

v2措施：

1. 按既有检测器角色定义，将动作background/相机subject标为not_comparable；不将其算作算法漏检，也不声称这种分母修正是算法提升。仅更改独立v2 AI标签副本，原标签不改。
2. 对预先指定的people01/people02原样120帧顺序联系表做AI审阅：步行/用手机自然连续，未见切镜或重播。新增subject的AI motion normal判断，范围仅该已审原样序列；不按分数挑正常样本。
3. 为这两源各构造一项三段原样对照。使用正式cumulative构造器的三段plan，再显式应用正式unchanged的中性RGB recipe；保持源帧顺序、PTS和每帧RGB摘要一致。只在独立AI自定义case中使用，不改原200控制或正式变体契约。已有原样颜色normal判断与顺序图为AI累计normal依据，冻结后再测量。
4. 相机跳变是短事件；case p90可能稀释单帧峰值。新增AI实验聚合`camera_peak_v2`取整段所有有效相机分数的最大值，其他项保持既有聚合。明确改变实验聚合身份，不改生产算法、支持门槛或普通profile。
5. 复用此前校准侧people02原样/重播/跳变的四区域背景试验，作为相机支持的独立开发对照；不挪进新检查集、不把背景修订当准确率证明。
6. 新Scott源先完成全96帧视觉材料、AI区域及各控制可见效果审阅，标签/区域/检查队列在v2拟合前封存。新检查包括原十变体及一项三段原样对照。新样例的真实弱可见/不适用项保留unverified/not_comparable，不因recipe强制正负。

仍用原构造、全原生帧核心和既有拟合函数；数据脚本每命令265秒、比较JSON分块不放宽资源上限。阈值拟合完成并冻结身份后才能运行新检查侧detector。检查只运行一次，不回看旧检查侧调整阈值。失败/弃权如实记录；最多给实验阈值和该单源检查结果，production_eligible=false。

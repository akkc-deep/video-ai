# VCO-06 media final-review corrections

Scope: `src/video_ai/runtime/_scene_color_repair_media.py`, addressing final-review findings 2 and 3. History, source-reference identity, recovered-terminal admission and fit scalar validation are handled by the parent session in their owning modules. Frozen calibration/profile files were not changed.

Saved media now requires candidate-owned `full-frame-checks.json` and `decoded-scores.json` Artifacts in `media.evidence`. The measured validator checks exact outer and row schemas, ordered coverage of every native frame, strict integer/finite numeric types, sample support, zero full-frame new clipping, zero parameter change and the two-code RGB roundtrip budget. Decoded residuals must meet p99 <= 2 and max <= 4, preserve each frame's MAE and clipping count, and strictly improve the sample-weighted aggregate. Aggregate MAEs are reconstructed from saved frame metrics and support using the scorer's integer-total arithmetic. A true `passed` flag cannot override missing measurements, failure reasons or contradictory frame values. Full runtime fit rows receive the same residual/improvement checks and their before measurements must equal decoded before measurements; no estimator is called.

New decoded evidence includes all-frame source-to-decoded clipping/change measurements and F-1 temporal differences: Euclidean distances between consecutive three-channel mean signed residual vectors over the unchanged pair coordinates. The applied parameter remains constant.

`frame_changes` measures clipping, changed-channel counts and maximum differences in chunks of at most 65,536 RGB pixels. It rejects noncontiguous inputs instead of silently copying an entire frame, and uses only bounded int16 and Boolean temporaries. Both rendering and readback use this helper. The spool hashes and writes a memoryview, and each source/intended/decoded full-frame buffer is released before advancing. Only the final decoded frame is copied for the tail PNG.

Tail PNG output streams filtered scanlines through bounded zlib/IDAT chunks, with explicit sRGB metadata and CRCs, then fsyncs and renames under the owned lock. This removes the shared PNG helper's full-frame scanline and chunk-concatenation allocations. Application/readback require at most two raw frame buffers plus bounded arithmetic buffers; the existing three-frame allowance also covers source-reference pair sampling. The parent removes its retained repaired sample list after fit scoring so the existing sample-support budget remains applicable.

Verification status: implementation and static readback complete. No tests or media commands were run by this scoped agent before the parent grants a serial test token.

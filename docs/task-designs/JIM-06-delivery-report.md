## Interface decisions

- Pure validation uses an exact expected wrapper `{'template': template, 'created_at': candidate_commit['created_at']}` to enforce the authentic lower viewing-time bound without adding a serialized observation field.
- Private facade validators accept the already admitted `context`: `require_scene_final_acceptance_record(context)` and `require_scene_delivery_record(context)`.
- `final_observation_state(context, *, candidate=None)` reconstructs raw failed states without writes. `scene_delivery_files.validate_delivery_state` validates partial and complete transactions without writes.
- Visual baseline bindings come from each selected image's `baseline_bindings`, separately from narration bindings in `scene_clips.scenes[*].bindings`.
- Original PCM SHA is read from `clip.pcm.path`; `ArtifactStamp` does not contain SHA. The builder performs no writes or services.
- Composition's admitted immutable byte captures and inventories propagate into the publication guard, including original encode/probe evidence and empty command logs. New observation files have their own separate inventory when admitted for delivery.

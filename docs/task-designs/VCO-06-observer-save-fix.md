# VCO-06 观察记录保存修复

2026-10-29。用户报告勾选后无法保存，页面提示“请明确目标颜色、结构、动作和光照意图；不确定时选择未确认”。

根因：保存按钮在导出任何内容之前，把中性/轻微色偏结论与target/structure/motion/lighting资格条件绑定；条件冲突时完全不导出原始填写。只有一条通用报错，用户无法知道具体哪项不满足。切换素材还会清空未保存内容；下载请求被当成保存完成，没有文本备用出口。

修复范围：仅改非冻结HTML模板、新增浏览器行为测试，生成一个保留原DATA/媒体身份的新页面。原collection、冻结Python/CLI、原视频及原页面快照保持原字节，不改科学校验。

- 完整且一致的记录仍导出原schema，继续接受原验证器检查。
- 未完成或冲突的填写允许原样导出为独立kind=natural_material_observation_draft_v1；保存请求不变更任何答案，不伪造播放，不变成可接受标签。
- 显示具体未满足项；下载之外始终提供完整JSON文本和复制出口，不声称已确认落盘。
- 按collection/video身份保存每段本地草稿，切换时恢复，存储不可用时仍能导出。
- 原页面不具备草稿缓存，不能声称修复会自动找回已丢失或仍仅存在旧页面内存的填写。先保留旧页，提供新页面；需要时说明这一实际限制。

验证：Node执行真实模板JavaScript，覆盖报告的语义冲突、有效原schema、浏览器下载失败、草稿切换/恢复和原播放保护；合成UI事件只证明软件，不是实际观看证据。Python通过bootstrap，定向测试串行，全库仍留VCO-08。零模型/GPU/发布/Git写入。

实施结果：初始4失败/1通过；修复后最终29项通过，exit0，见 `docs/task-handoffs/VCO-06-observer-save-fix.md`。新版导出页与旧页DATA相同，旧页和4个冻结Python/CLI身份未变。没有生成实际用户观察或使任何草稿取得资格。

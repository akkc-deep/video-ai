# VCO-03 AI实验校准

2026-10-25，用户明确选择：“ai校准的就可以，我不想填表格”。本路线由AI完成实验输入、标注整理、阈值拟合与回放评估，不要求用户填写表格。原双人正式benchmark协议和记录独立保留，不能阻塞本路线，也不能被AI结果冒充完成。

复用原24位置、12个校准组/12个检查组及全部原生帧；不因分数替换来源或移动组。来源独立性仅有现有媒体血缘检查，未解决的生成身份作为实验限制。新增4源使用明确标为AI的粗框/逐帧草稿；保留原ROI和真值文件。当前4源全帧辅助检查结果分别记录，不把像素可配准等同语义身份。

实验标签以已封存表中的**历史AI建议**为弱标签，复制到独立AI标签文件，作者类别明确为AI，原表不改。正常/异常/不可比/未验证保留原值及理由，不按控制变换名称自动强制正负。新增40个case无独立AI判断时先保留unverified；不编造观看时间、真人或裁定者。标签及分组在任何拟合前绑定到输入/软件身份并封存。

复用原构造器、测量核心、case p90聚合、阈值拟合和指标函数；不修改生产算法或阈值支持门槛。控制构造可消费本路线的AI annotation，但其来源与AI-only用途必须随实验manifest和输出保留。原20源的200控制配方按兼容目标精确重放；新增40个AI实验控制单独计数。

测量按source/case独立有界运行并持久化；不重复生成逐pair相同PNG，比较数和原生帧不裁短。每命令最多265秒，失败保留现场和已完成case；分批数据采集与一次拟合/检查分开，拟合汇总操作最多600秒。只运行校准侧，封存六个阈值/不可用原因后才允许检查侧测量；检查侧不参与重拟合。已在前轮看过的人物诊断、AI标签与构造意图的相关性使本实验不构成盲评。

交付独立 `experimental-profile.json`、完整源/标签/阈值身份、逐case结果、分层指标/覆盖/弃权和失败记录。`experiment_kind=AI_experimental_calibration`、`production_eligible=false`；不创建能被普通分析接口误认为real_benchmark的profile，也不改写fixture_only用途。

六项可给数值阈值或明确的null及原因，失败或覆盖不足不隐去。实验完成意味着预定输入均有测量结果或显式失败、拟合和一次检查已留证；不要求凑出六项通过，不将训练误差当通用准确率。用户无需补表，后续可基于结果决定是否扩大独立验证；本轮不启动VCO-04或生产准入。

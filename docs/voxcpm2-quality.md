## 样本与控制变量

两引擎使用同一份现有生产参考音频的实验副本，启动前只核对一次小型参考文件 SHA256：`c7b31d6dbe7cc6a716dded00550db5b50940bf209e424e4ad207b12e657c8ff6`。来源、原始路径、voice.json 与模型路径保存在原始 `result.json`；这是既有配置音色的对照，不新增外部人物声音或声称新的授权证明。

对照有 9 组：67 字短文案，38 字同文案的七种情绪，235 字长段落。短文案覆盖阿拉伯数字、日期、小数、NASA、公里、银行/行长、重新、满载及运行。情绪为 narrative、gentle、mystery、excited、sad、angry、whisper，期望标签只在独立答案文件中保存。情绪指令使用锁定 VoxCPM2 API 支持的括号描述。

GPT-SoVITS 不提供相同的指令接口，使用原有固定音色和原文，不将情绪描述加入朗读内容。七个情绪配对复用同一条 GPT 基线，明确标记 `reused=true`，仅三个独立 GPT 请求；七条 Vox 情绪样本分别真实生成。这个实验可以检验 Vox 的情绪可辨识性，不能冒充两个情绪控制系统之间的等价参数比较。

GPT-SoVITS 沿用现有 CPU、FP32、v2、batch=1、非流式 WAV 参数，额外显式记录 seed=42。复制服务 YAML 到实验目录，选择独立 loopback 临时端口，只启动和终止本次子进程；Windows `terminate()` 后退出码 1 是主动终止记录，不能用作生成失败判据。API 成功响应与实际 WAV 才是生成证据。

VoxCPM2 沿用 [任务 01](voxcpm2-deployment.md) 的模型与源码冻结，GPU BF16、cfg=2、steps=10、seed=42、max_len=1024，关闭 normalize、denoise、retry_badcase、compile。模型只加载一次，独立 warm-up，比较样本和长文案均为随后串行推理。RTF 包含参考特征构建及模型推理，写盘/合并另记。CPU/GPU、32/48 kHz 以及不同分段机制均是现有部署差异，不能把耗时差异归因于模型本身。

长文案使用现有 `0002-旅行者2号-即梦版/input/script.txt` 的冻结副本，3,731 个 Unicode 字符，按既有 lossless span 边界合并为 31 个约 120 字单元。保留原文半开范围，逐单元记录实际起止样本、参考身份和轮次。原稿不足 30 分钟时循环从头生成，每次均实际推理，绝不重复拼贴已有音频充当生成；这是固定音色、长时串行压力实验，不声称测试了独有的 30 分钟文案。模型每段以同一参考克隆，不使用实验性续接。拼接只连结原始 PCM，不补停顿、改响度或执行生产后处理。

## 复现

```powershell
# prepare 输出新的实验目录；以下步骤使用这次输出的路径。
.\scripts\experiments\run_voxcpm2_quality.ps1 -Phase prepare -LongText '<原稿路径>'
.\scripts\experiments\run_voxcpm2_quality.ps1 -Phase baseline -OutputDirectory '<实验目录>'
.\scripts\experiments\run_voxcpm2_quality.ps1 -Phase voxcpm -OutputDirectory '<实验目录>'
# 仅重建试听页面，不重新推理。
.\scripts\experiments\run_voxcpm2_quality.ps1 -Phase package -OutputDirectory '<实验目录>'
```

默认长时目标为实际输出 1,800 秒，`-LongSeconds` 可设置实验长度。5/10/30 分钟检查点是第一次越过该时长的完整单元累计值，报告精确实际时长。加权 RTF 为真实生成耗时之和除以实际音频时长之和，不平均各段 RTF。首次输出单独记录，不用其代表热推理。实验阶段不自动重试；已有生成记录的目录拒绝重新推理，失败诊断与已生成产物保留，应新建实验目录重做。

## 试听与验收

对照生成完成后，打开实验目录 `blind/index.html`。随机排列题目及每题 A/B 引擎身份，音频文件使用匿名名称，页面不读取答案映射。听完记录偏好、实际听到的情绪、漏读/重复/发音、自然度与尾音，再点击“导出试听记录”。`blind-key.json` 单独保存，提交前不查看；原始音频不做响度处理，试听需留意音量差异。

长文案生成结束后，页面另附同文案起点/终点音色对照及完整长音频。这部分明确为非盲测。至少覆盖前、中、后音色、段落边界与尾音；只比较参考路径不能证明无漂移。用户可提交页面导出的 JSON，或按 P01–P09 给出实际试听结论。未填项目不代表通过。

必须分别判定：中文完整与发音、至少六种情绪可辨识、长文案音色稳定、拼接/尾音、实测性能与是否继续。只报告已提交的主观证据。本次已收到真实记录，原始报告记为 `subjective_listening=received_and_reviewed`；未作判断的项目仍保留未验证，不把生成标签、无报错或 WAV 合法性当作主观通过。

用户提交了上述原始记录，试听人：强志伟，记录时间 `2026-11-24T18:45:03.877Z`（北京时间 2026-11-25 02:45:03.877）。提交后才按实验目录的 `blind-key.json` 解盲。仅解析记录及映射，没有重新生成、解码或分析音频；原始记录的 SHA256 和完整逐题评审保存在实测 JSON 中。

对音质的正面证据也保留：P01 的 Vox 获评“有情绪、停顿合适”，P02、P03、P04、P05、P06、P07、P09 的 Vox 获评“没问题”或同义描述。相应 GPT 样本出现“声音不合格”“声音不好”“断断续续”及“听不出来语气”等意见。这表明该听者在本组样本中偏好 Vox，不能用情绪不达标抹去这一结果。七个情绪题共用同一 GPT 基线，而且只有一名听者、一份参考音色，不能把偏好计数推广到其他文案、音色或人群。

`fixed_voice_notes` 原文只有“目前”，没有可用的首尾/前中后音色判断，因此长时音色稳定性仍为未验证。“没问题”的总体评价也不等于逐项确认数字、英文、多音字、漏读、重复及尾音均通过；这些专项验收仍为未验证，不能自动补成通过。

两引擎均真实完成全部对照。GPT 服务就绪耗时 88.355 秒（含 Python 导入、模型加载与轮询）；Vox 模型加载 10.121 秒（不含 Python 导入）。Vox 首次带参考预热生成 2.72 秒音频耗时 53.154 秒，RTF 19.542；它不计入下表热推理。这个冷请求成本不能遗漏。

| 短文案 | 12.16 | 9.443 | 0.777 | 16.54 | 44.603 | 2.697 |
| narrative | 7.20 | 5.197 | 0.722 | 7.94 | 3.420 | 0.431 |

| mystery | 8.00 | 6.622 | 0.828 | 7.94 | 复用 | 复用 |
| excited | 6.88 | 4.985 | 0.725 | 7.94 | 复用 | 复用 |
| sad | 8.48 | 7.211 | 0.850 | 7.94 | 复用 | 复用 |

| 长时检查点 | 实际累计音频秒数 | 累计生成秒数 | 加权 RTF | 完整单元数 |

这些是同一次常驻模型串行实验的累计检查点，并非三次独立冷启动基准。没有把单元间写盘耗时、报告写入或试听页面生成计入模型生成 RTF；阶段总耗时另存于原始报告。

长时输出为 30 分 21.44 秒、48 kHz 单声道 PCM16，87,429,120 个采样点，共 79 个单元，覆盖原稿两整轮与第三轮的前 17 个单元。`long-narration.wav` 合并总样本数等于所有片段之和，合并耗时 0.073 秒。所有 9 个 Vox 比较样本合计的加权 RTF 约 0.766；长时生成没有达到 0.3 目标。

本实验进程 PyTorch 峰值 allocated/reserved 分别约 6.548/8.004 GiB。Vox 阶段入口总耗时 1545.766 秒，包含 Python 导入、环境记录、模型加载、预热、对照样本、长文案、终点样本、写盘与报告；不含解释器退出。Vox 生成进程正常退出，退出码 0。原始音频、匿名副本、参考副本、完整环境 freeze、服务日志与 `result.json` 均留在本次实验目录。

试听页现已加入起点/终点样本及完整长音频；如在生成过程中打开过页面，需刷新查看。人工评分已收回并按上述口径评审，不声称六种情绪可辨识、没有漏读/重复/错音，或长时音色没有漂移。原始记录已复制到实验目录 `listening.json`，实测报告的归档副本与实验目录副本同步更新。

## 必要验证

输入只冻结一次；每个新输出只检查数组有效性及一次 WAV 头/样本数，合并时核对总样本数。没有生成期权重哈希、全量 ASR、重复解码、GPU 租约或生产监控。独立实验脚本及 PowerShell 入口已通过语法解析。对照材料检查确认 9 个配对、7 个情绪题和 18 个匿名 WAV，页面未引用答案或引擎路径。独立只读审查未发现重要问题。最终元数据核对确认三档检查点、79 段、总样本数和交付文件齐全，未执行额外音频解码或重推理。
